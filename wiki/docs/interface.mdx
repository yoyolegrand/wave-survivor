# Interface & commands

## On screen

- **Event feed** (left of the screen): chaos events, Breaches, Catalysts, merchants and objectives show up here instead of in the chat, for a few seconds each.
- **Wave bar** (top): monsters left, wave number, countdown to the next wave and pauses.
- **Treasury panel** (right, Kingdom mode).
- **Arrows**: some roles get a HUD arrow (the Arcanist towards Catalysts and corruption hearths, the Miner towards deposits). The Buried Treasure objective gives one to everybody.

## Commands for everyone

`/ws codex`: this guide
`/ws info`: current horde, wave and monsters left
`/ws resume` and `/ws abandon`: resume or drop an interrupted game
`/ws retry`: reconsecrate a fallen altar and try again
`/ws benediction liste`: blessings catalogue
`/ws pacte list`: Blood Pacts
`/renaissance`: opens the Renaissance menu; `/renaissance shop` and `/renaissance points` (your RP)

<Callout type="info">This page mirrors the in-game **Codex** (`/ws codex`). Values are the defaults: most of them can be changed in the config or the in-game editor.</Callout>
