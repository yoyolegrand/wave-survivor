# Bourse à clés

La **Bourse à clés** range tes clés de coffres roulette et les utilise à ta place.

## Contenu

- Clic droit dans le vide : ouvre la bourse (27 cases par défaut). Seules les **clés de coffres roulette** y entrent.
- Le contenu reste dans l'objet : tu peux la ranger, la jeter ou la donner.

## Ouvrir un coffre

- **Sans clé en main**, clic droit sur un coffre roulette : une clé du bon type est prise dans ta bourse (n'importe où dans l'inventaire).
- **Accroupi** + clic droit : toutes les clés de ce type sont utilisées, avec une seule animation accélérée puis un écran de résumé de tous les gains.
- Une clé tenue en main reste prioritaire.

## Ramassage automatique

- Les clés ramassées vont directement dans la bourse. Accroupi + clic droit dans le vide pour l'activer ou le couper.

## Fabrication

- 4 cuirs, 2 ficelles, 1 lingot d'or et 1 pépite d'or (établi). Réglages dans **rules.json** : taille, ramassage automatique, ouverture en série.

<Callout type="info">Cette page reprend le **Codex** du jeu (`/ws codex`). Les valeurs indiquées sont celles par défaut : la plupart se règlent dans la config ou l'éditeur en jeu.</Callout>
