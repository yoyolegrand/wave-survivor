# Boss

Les boss surgissent à des vagues précises, annoncés dans le chat. Certains invoquent des sbires, s'entourent de **totems protecteurs** (à détruire pour les rendre vulnérables) ou vous attendent dans leur **arène** : un portail s'ouvre alors près de l'autel après la dernière vague.
Un boss peut aussi porter des affixes qui changent sa façon de combattre.

Les attaques puissantes sont **annoncées** : zones qui s'allument, lignes au sol, particules. Regarde le sol et bouge. Certaines mécaniques demandent de **coopérer**.

<Callout type="info">Cette page reprend le **Codex** du jeu (`/ws codex`). Les valeurs indiquées sont celles par défaut : la plupart se règlent dans la config ou l'éditeur en jeu.</Callout>
