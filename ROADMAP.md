# 🗺 Wave Survivor — Roadmap

*Ideas and plans — not promises. Suggestions are welcome!*

## 🔜 Next updates
- ⚖ **Difficulty levels** — Easy / Normal / Hard / Nightmare per horde (monster HP, damage, wave size)
- 🔮 **Iron's mage spell lists** — choose exactly which spells each Iron's mage casts
- 🏅 **Advancements** — "First horde survived", "Morvhal defeated", "All relics found"…
- 📊 **Player statistics screen** — hordes won, monsters killed, bosses defeated, best rank
- 📤 **Horde sharing** — export / import a horde as a code or file to trade your creations

## 🧭 Planned
- ♾ **Endless mode** — infinite waves with growing difficulty and a best-score leaderboard
- 🎲 **Horde mutators** — optional modifiers before starting (faster monsters, no regeneration, enraged bosses…) for better loot
- 👑 **Boss Rush mode** — fight all the bosses of a campaign back to back
- 🗺 **New hordes** — Frozen Peaks, Jungle Temple, Pillager Siege, Deep Dark Abyss (Warden), Sky Horde
- ⚡ **New chaos events** — meteor shower, Blood Moon, storm, earthquake
- 💍 **Relic set bonuses** and a **relic forge** to upgrade them
- 🛡 **Classes** — pick Tank, Archer, Healer or Mage at the start of a horde
- 🎵 **Boss music & sounds** — a unique theme for each final boss

## 🔭 Later
- 🏘 **World hordes** — random invasions of villages, outside of altars
- 🏛 **Ready-made arenas** — structures generated around the altar (ruins, temple, fortress)
- 🧩 **Creator API** (KubeJS / datapacks) — add skills, hordes and relics without touching the code
- 🆙 **Port to newer versions** — Minecraft 1.21 / NeoForge
- 🎨 **Custom models** for the bosses
- 🌍 **More languages** and an **online wiki**
